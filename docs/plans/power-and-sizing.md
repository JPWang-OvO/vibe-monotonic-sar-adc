# 目标与边界

从 `checkpoint/ai-autonomous-human-polish-r1-20261024` 开始，在原系统规格内降低每次转换能量，
优先去掉采样网络、相位驱动和数字控制中的过设计。本文是待实施方案；checkpoint 的电路、
已通过结果和原验收配置保持冻结。

保留 10 bit、50 MS/s、1.8 V 电源与参考、原差分输入范围和 −1 dBFS 激励，
250 MHz 外部主时钟及片内分频、顶板采样、向下单调 CDAC 和异步逐位控制。
全部有源电路保持晶体管级，不加入数字校准。输出仍接每位 10 fF 负载。
低频与中频 SNDR 门槛分别为 57.0、56.5 dB，最终仍使用原来的 20 个 PVT/噪声 case。
当前约 60–61 dB 的部分测试余量可以参与功耗权衡；每个 case 同时报告与 checkpoint 的 SNDR 差值。

用户已明确新的实现边界：短时瞬态 SOA 电压超限可接受；允许 2 V 自举器件的 G-B 超压；
采样窗约 4 ns 是标称时序，采样建立和后续转换完成决定实际可用范围。
SOA 警告保留供观测，允许的上述情况不触发失败或自动增加阻尼、保护电路。

原任务明确要求功耗仅报告。上一版本的主要问题，是把自行分配的局部预算逐渐当成必须逐项满足的
硬门槛，并通过加尺寸、加电容推进。新的优化以完整系统性能约束下的实测能量为选择依据，
不再用独立模块的过高分数代替系统目标。

# 先重新定义验收层次

以下调整在候选仿真开始前形成新的版本化验收配置；保留 checkpoint 的旧配置用于解释历史结果。

| 现有判据或选择 | 审查结论 | 下一轮使用方式 |
|---|---|---|
| 两频点 SNDR 57.0/56.5 dB；10 bit、50 MS/s | 原任务硬规格 | 保留；不得降采样率、挑输出窗口或改幅度达标 |
| 每周期十次比较、唯一 EOC、正确位序、输出保存与保持、启动成功 | 电路功能要求 | 保留；真实遗漏转换、错误复位、竞争冒险必须解决 |
| `period_error_s <= 1 ps` | 自定的过严门槛；计算的是相邻 Sample 下降沿间隔对 20 ns 的偏差 | 撤销独立失败门槛。核对分频计数与平均采样率，保留边沿变化记录；输入相关孔径变化及随机抖动的影响进入实际输出 SNDR |
| `sample_window = 3.5–4.5 ns`，以及围绕 4 ns 精确调边沿 | 标称相位被过度约束 | 保留约 4 ns 的设计意图。检查实际导通窗能否建立、关断后能否完成转换；不追求绝对延迟或窗宽误差归零 |
| 固定采样结束后 14 ns 读码、EOC 至下次采样至少 2 ns | Agent 选择的实现接口及额外裕量 | 依据“下次采样前结果稳定”和实际输出建立时间重新分配。先固定一个所有候选共用的读码相位，再验收；不能为每个失败 case 单独移读码点 |
| 采样模块 SNDR ≥70.17 dB | 从局部预算推导的筛选值，显著高于系统规格 | 改为诊断。候选是否保留由完整 ADC 的 SNDR、能量和时序决定 |
| 采样静态误差 ≤0.1 LSB、保持漂移 ≤0.05 LSB、馈通 ≤0.08 LSB | 有助定位问题，但各项同时硬卡会重复留余量 | 测量并区分固定增益/偏移、信号相关误差和噪声；按系统可用误差预算分配，不独立触发尺寸膨胀 |
| CDAC 非线性残差 ≤0.1 LSB；系统逐位 RMS ≤0.7766 mV | 初始预算及旧参考模型的阈值 | 保留波形诊断，更新到当前候选实际电容与寄生。最终以原始输出性能和正确转换为准，不能用参考模型修正输出码 |
| 底板必须先进入距电源轨 0.18 V 内 | 把数字电平标准套给模拟建立节点 | 改为比较器实际判决时刻的顶板差分残差；不同权重的底板允许残差不同 |
| 第一比较时采样栅极绝对电压 <0.2 V | 对特定旧拓扑的代理指标 | 检查实际 VGS、采样路径是否仍导通、关断后对保持电荷的扰动。保留必要的关断与比较顺序 |
| 自举 VGS 必须为 3.0–3.6 V | 双级 5 V 器件实现带来的目标 | 删除；2 V 单级自举以约 VDD 的 VGS 为初始设计意图，由 Ron 和失真决定允许压降 |
| `soa_warning_count = 0` | 与本轮用户允许的超压边界冲突 | 撤销零警告门槛；报告波形和异常类型，允许的短时超压及 G-B 超压不驱动改电路 |
| 比较器全模块扫描统一 ≤1.3 ns，Bias 固定 0.75–1.4 V | 初分配时间及内部偏置代理值 | 根据真实共模、输入差分、再生和总转换时间分配；偏置节点电压用于解释工作状态 |
| 瞬态噪声上限 50 GHz | 当前测量设置，需要物理带宽与折叠依据 | 候选对比先沿用同一设置；只在采样/再生噪声带宽证据支持时做一次代表性收敛检查，不能为提高 SNDR 缩窄频带 |
| 理想层逐码一致、晶体管层远离边界的错误判决检查 | 前者验证算法；后者用于发现确定性故障 | 保留算法正确性。非理想层结合实际节点和系统结果解释，不能把旧理想参考的每个微小偏差都当成器件需增大的证据 |

正式输出电平判定继续使用原 0.18/1.62 V 阈值。内部模拟节点按其功能判断，
不会因为它尚未到某个数字电平就提前宣告转换失败。

# 标准单元复用清单

先使用已确认存在的 `standard_cells` 晶体管网表；更强驱动档、专用 latch 或复合门需先查询实际库。
保留库原生器件参数。每次替换核对端序、反相关系、时钟边沿、复位/预置极性和负载。

| 当前模块 | 计划 |
|---|---|
| SAR_NAND2、SAR_SELECT | 普通 NAND 功能统一映射到 ND2D1BWP7T 或库中实际可用的合适驱动档。选择逻辑与末级大电容驱动分开定尺寸 |
| SAR_INV、SAR_INV_SMALL、SAR_DRIVE 的普通逻辑用途 | 使用 INVD1BWP7T 及查到的驱动档，按输入电容和负载选择必要级数，保持输出极性 |
| SAR_DFFR、SAR_ARM | 优先恢复 DFCNQD1BWP7T，取消为压过冲而派生的电容和全器件 ×4 倍乘；随后检查真实时钟与数据路径 |
| SAR_DFFS | 优先恢复 DFSNQD1BWP7T，保留正确的预置及上电状态 |
| SAR_OUTPUT_FF | 首先评估 DFQD1BWP7T 的实际 clk-to-Q、输出负载和接口时序。只有库单元在合理外部时序下确实不足时，才保留小型定制实现 |
| SAR_FAST_SEQ | 使用复位 DFF 库单元表达逐位状态，处理现有 Reset 极性；核对 Valid 驱动后的推进、复位和同沿竞争，避免因换单元破坏异步握手 |
| SAR_WAIT_GATE、握手与复位组合逻辑 | 将逻辑函数映射到已有 NAND/NOR/INV；NOR 可用 NR2D1BWP7T、NR3D1BWP7T。取消因零 SOA 告警而形成的 240 fF 栈节点电容及相应 22 µm 强下拉 |
| SAR_HANDSHAKE、SAR_DONE_DELAY、采样保护链 | 仅为实际建立/保存/关断顺序保留延时；评估库内 DEL0BWP7T 或必要的反相器链，不维持旧延时数值本身 |
| SAR_CAPTURE_LATCH | 先核查可用锁存器及其极性；若库中没有匹配单元，保留一份小型传输门 latch。其输入门、保持环和输出分别按负载定尺寸 |
| SAR_CMP、SAR_BIAS、采样自举、POR、SAR_DAC_DRIVE 末级 | 保留必要的模拟定制功能。比较器后级数字感测/逻辑仍复用标准单元；DAC 末级允许按各位模拟 RC 负载定尺寸 |

标准单元替换采用满足实际时序的最小可用驱动档。更换 Valid 感测路径时，必须核对
“判决稳定后才发完成信号”；上一轮已发生过内部共模暂态导致 Valid 过早的问题。

# 尺寸重新推导的顺序

## 1. 采样、自举与 CDAC 联合处理

优先试验 2 V 器件的单级自举。原实现的两级 5 V 自举、每级 80 pF、1024–2048 µm
辅助开关、256 µm 主采样管和 384 µm 结补偿管全部失去直接沿用的依据。
先在原 CDAC 负载上验证新拓扑的功能，再逐步减小 CDAC 并重新求开关与自举尺寸。

CDAC 的初始候选为单位电容 24、12、8、4.8 fF，对应每侧 12.288、6.144、4.096、2.4576 pF。
这是建立权衡曲线的少量候选，不是四项同时穷举所有其他尺寸。
4.8 fF 来自[参考论文](https://scispace.com/pdf/a-10-bit-50-ms-s-sar-adc-with-a-monotonic-capacitor-hcl5rch1mj.pdf)
的数量级；在本项目允许理想线性电容的范围内，最终由噪声和信号相关寄生误差决定。

尺寸推导使用以下关系作为起点，然后用真实晶体管波形核对：

- 差分采样热噪声估算为 `sigma_diff ≈ sqrt(2 k T / C_side)`。
  在 125°C、每侧约 2.46 pF 时约为 67 µV，即约 0.019 LSB。
  因此不能仅以 kT/C 为由坚持每侧 12.288 pF；开关、比较器与控制噪声另计入系统仿真。
- 一阶建立要求为 `Ron * C_total <= T_track / ln(deltaV_step / epsilon)`。
  例如把阶跃压到 1/2048、实际跟踪时间为 4 ns 时，每侧 2.5 pF 的 Ron 上限约 210 Ω，
  12.288 pF 时约 43 Ω。该例用于说明电容对驱动的影响，epsilon 最终来自系统预算。
- 在实际输入范围和慢角提取 Ron(W, VGS, Vin)，由上式求主开关宽度，再检查正弦跟踪失真。
  不把主开关 256 µm 当作新拓扑起点。
- 由主开关栅电荷和辅助器件寄生得到 C_load。自举电容的初估为
  `C_boot >= C_load * (VDD / deltaVGS - 1)`，并计入保持期间漏电荷；
  deltaVGS 根据 Ron 变化和系统失真确定，随后验证实际浮动节点。
- 预充电、传输和复位开关按其实际电容、摆幅与可用时间求 RC，逐支路选择宽度。
  栅极约为 Vin+VDD 的 G-B 超压属于用户允许范围。
- 主开关及输入寄生改变后，重新测量馈通和电荷非线性。原 384 µm PMOS 结补偿、28 fF
  交叉补偿先撤出候选，只有残余信号相关误差需要时再引入经推导的小补偿。

自举电容并非每周期都从零充至 VDD，其功耗以实际电源电流积分为准，不能直接用
全部 C_boot 的 C·V²·f 当作测得功率。

## 2. 采样相位和互补控制驱动

现有 SAR_PHASE 的 1/8/64/512/4096/32768 倍链及 SAR_INV 的 8/48/256 倍链重新选型。
在新自举负载确定后，读取总栅电容与布线前的器件寄生，确定所需边沿和两相相对时序。
以总电气扇出 H=C_load/C_in 和初始级扇出约 3–4 估算级数，再比较相邻两种级数的能量与建立。
最终尺寸由每级实际负载反推，取消固定 32768 倍末级。

相位逻辑允许固定传播延迟和实际采样窗偏离 4 ns；需要保证每 20 ns 一次采样、采样路径正确关断，
并给转换留足时间。输入相关关断时刻变化仍会影响 SNDR，直接观察其系统结果。

## 3. DAC、控制与存储

- 每位 DAC 负载为实际权重电容及寄生。由该位切换到下一次比较的时间、底板变化幅度和
  顶板残差求 Ron；近似关系为 `deltaV_top = (C_bit / C_total) * deltaV_bottom`。
  大权重与低权重的残差要求不同，重新确定末级 N/P 宽度及前驱动链。
- 当前 MSB 末级倍率 256，对应 N/P 合计 512/1536 µm；取消直接按旧 strength 复制尺寸的做法。
  数字选择门只驱动前级输入，普通逻辑优先使用标准单元。
- 删除纯为抑制允许过冲而加入的 Clock 320 fF、WAIT_GATE 240 fF 及 DFF 存储/栈节点补偿候选，
  一组功能相关修改一组验证。POR 定时电容、真实保持需求等有功能作用的电容单独处理。
- 复位、Valid、序列时钟及 EOC 的驱动按实际扇出定尺寸。检查同沿数据竞争和异步反馈，
  不用统一放大整套 DFF 或增加整条延时链处理局部问题。

## 4. 比较器与偏置最后收敛

先保留当前比较器，便于分离前端与控制修改的影响。前端电容和控制负载收敛后，
再评估输入对 8 µm、再生对 8 µm、偏置/时钟 PMOS 48 µm、偏置下拉 3.6 µm 的必要性。
输入对由噪声、动态共模误差与输入负载确定；再生对由决策时间和输出稳定性确定；
偏置电流由最慢实际比较及总转换时间确定。降低电流时一并检查 Valid 是否提前。
输出缓冲功耗仅约 0.018–0.025 mW，作为末尾的库映射整理，保持外部负载和测量边界。

# 实施与验证顺序

| 阶段 | 电路/工具工作 | 最小验证与继续条件 |
|---|---|---|
| 0：测清基线 | 在保留电路上记录互不重叠的模块供电端口电流：分频/相位、互补驱动、自举/采样、比较器/偏置、异步/寄存器、DAC/参考及输出 | 已有总功耗直接复用；缺少模块电流时补一个 TT 稳态诊断 case。各分项之和与供电总积分闭合；父级与子级不重复计数 |
| 1：前端与相位 | 2 V 单级自举、主开关及电容缩减，配套重新推导相位驱动 | 模块只测实际相关输入范围和建立；先用 TT、SS/125 的短系统转换定位问题，再用原两频点 256 个码确认性能，不把短窗 FFT 当正式通过 |
| 2：标准单元与数字尺寸 | 分频/存储复用库单元；组合逻辑映射；重新定 DAC 驱动和必要延时 | 对改变的上电、复位、保持、Valid 路径做针对性检查。TT/SS 热角覆盖建立，FF 冷角覆盖快速竞争；仅在证据需要时增加局部条件 |
| 3：模拟余量收敛 | 比较器/偏置电流和再生尺寸调整；对收益最大的尺寸向更小一档试探 | 比较同一激励下的能量、SNDR 和完成时间。性能不足时定位限制支路，避免全局回到大尺寸 |
| 4：固定设计验收 | 锁定同一候选、读码接口、输出负载、噪声设置和测量窗口 | 执行原 20 个正式 case：TT 无噪声 2 项、TT 含噪声 2 项、四个极端条件各有/无噪声两频点共 16 项；全部结果属于同一电路 |
| 5：OA 更新 | 从收敛网表更新必要 schematic，保留 checkpoint 和人工图面；同步变化的接口 | 原生导出与优化候选逐层端口、有效尺寸和连接等价；只审阅实际修改的视图和受影响父级 |

每次改变模型、尺寸或连接都重新生成该候选的 PDK 补全参数。候选和基线使用相同仿真器与精度，
继续遵守 Spectre X AX 设置，不用积分步长或收敛设置为候选制造优势。
开发先筛掉功能失败和明显劣化的方案；完整噪声/PVT 矩阵在候选收敛后执行。
不重建已经正确的 Python/Verilog-A 算法层，不新增 Monte Carlo、全频扫描或静态线性度验收。

候选记录包含：系统 SNDR、转换完成与输出稳定、各模块能量、VDD/参考/时钟输入功率、
关键宽度与电容及其来源。新尺寸必须能指向实际负载、时间或误差依据。
比较参考论文时扣除输出缓冲；同时保留含缓冲总供电功耗，避免改变统计口径。

# 决策与停止条件

优化问题写为：在上述系统性能和功能约束下最小化 `E_conversion = P_total / 50 MHz`。
当前 TT 基线约 193.7 mW，即约 3.87 nJ/转换。首要收益应来自前端和相位驱动，
其确切占比在阶段 0 测量；本文不承诺尚未验证的最终 mW 数字。

模块测试用于缩小问题范围，最终系统结果决定候选去留。保留功耗—性能曲线中有意义的少量候选，
避免把每个内部电压、每个边沿和每项局部误差都变成新的规格。
最终候选通过原系统规格、消除已识别的大倍率/大电容来源，且继续缩减的主要支路已显示明确的
性能代价后，完成 OA 核对并交付；其他小收益优化记录为后续工作。
