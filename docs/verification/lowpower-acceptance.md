# 验收结果

当前晶体管电路已完成 20/20 项系统验收，全部通过。正式基线对应设计版本 `90c6f6a`，
覆盖补齐 SAR_BOOST 串联复位管及 SAR_BIT strength 重定义后的实现。比较器与分频器的独立功能 flow 各有 5/5 项 PVT 条件通过。
原生网表及图面核对见 [低功耗 OA 交付](lowpower-oa-delivery.md)。

每项采用丢弃 16 周期后的连续 256 个原始输出码，统一在 Sample 下降后 18 ns 读码。
十次比较和唯一 EOC 必须在下一 Sample 上升沿前完成；输出寄存器保持结果直到下一 EOC。
Spectre AX 使用 8 线程、5.8 µs 瞬态窗口。噪声请求频带为 1 Hz 至 50 GHz、seed=1；
Spectre 19.1 的日志记录实际下限约 172.414 kHz，上限为 50 GHz。核心功耗包含参考供电并扣除输出缓冲；论文比较值为 0.826 mW。

TT 核心功耗为 2.0424 至 2.0786 mW，满足 3 mW 门槛。系统 SNDR 为 59.320 至 61.441 dB，
全部高于 59 dB，并满足低频/中频 57/56.5 dB 的验收下限；最小转换余量为 0.810 ns。

# 结果与日志

`baseline_20261026_02_system` 提供 FF 两个温度及 SS/125°C 的 12 项结果；
`baseline_20261026_03_remaining` 提供 SS/−40°C 与 TT/25°C 的其余 8 项结果。两批 DUT 源一致，条件完整且无重复。
全部作业通过执行、日志审阅、测量、功能和性能检查。实际码、频谱、逐位轨迹、模块功耗和完整日志保存在本地批次目录，路径见基线 JSON。
PDK 参数提示和瞬态 SOA 警告保留在日志中，按现有验收规则审阅。
验证覆盖固定 256 点、单种子及规定的 PVT 矩阵；失配 Monte Carlo、DNL/INL 和全频段扫描尚未验证。
