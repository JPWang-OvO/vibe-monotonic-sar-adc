# 诊断结论

SNDR 优化目标为 59–60 dB，TT 核心功耗上限为 3 mW，低频/中频验收下限为 57/56.5 dB。
限制项包括 DAC 建立不足，以及近零差分时 Valid 提前触发复位造成的判决捕获竞争。
以下以 4 µm 输入对、DAC8 驱动及四级前五位建立延时的候选为诊断起点。
最终采用 DAC16 驱动、四级前五位建立延时、4 µm 输入对和 2 µm 再生对。
同一版本的全部 20 项通过，SNDR 为 59.223–61.880 dB，TT 核心功耗为 2.041–2.076 mW；
最小转换余量为 0.763 ns，OA 原生网表与该验收电路一致。
这些诊断与尺寸收敛结果对应串联复位管补齐前的版本；当前复位拓扑的 20/20 项验收结果见[正式基线](lowpower-acceptance.md)。

# 59–60 dB 所需的误差水平

诊断窗口的基波约 324 LSB RMS。59/60 dB 分别对应总残差约 0.364/0.324 LSB RMS；
理想均匀量化噪声的参考值为 0.289 LSB RMS。
比较器约 0.5 mV 输入等效噪声对应约 0.142 LSB。
若按互不相关的误差作平方和估算，含噪声达到 59 dB 时，无噪声残差需约 0.335 LSB 或更低；
达到 60 dB 则需要接近理想量化水平。
这个估算用于判断改善方向，实际结论仍以未校正输出码的完整系统仿真为准。

无噪声 FFT 残差包含量化误差与码边界相关的确定性成分；随机噪声由独立比较器测试和系统含噪声测试表征。

# DAC 建立与动态判决

逐位记录显示，FF 高温的若干高权重位在比较开始前仍有较大的建立残差。
去除该位数据对应的线性电荷增益与固定偏移后，bit 7/6 的开始时刻差分残差 RMS 为约 32.5/32.5 mV，
TT 为 17.1/22.9 mV；到最后两位，FF 对应残差已降至约 0.05 mV。
这些数值描述比较开始瞬间的建立状态。比较器在随后评估期间仍响应变化的输入，最终码误差取决于该动态判决过程。

进一步检查第 16 个转换的 bit 7：FF 高温在该位比较开始时，上一位切换的底板仍为 0.437 V，
100 ps 后降至 0.096 V；对应 TT 为 0.343 V 和 0.056 V。
这个 FF 样本的码相对基波拟合残差为 +1.362 LSB，TT 为 −0.323 LSB。
该波形显示 DAC 切换与下一次比较评估重叠；尺寸和延时对照用于检验这一重叠对最终码误差的贡献。

同一 FF 样本的 bit 4 更直接显示动态判决问题：比较前输入为 +14.136 mV，Valid 时输入已变成 −3.793 mV，
输出仍锁存为 1。此处上一位底板在评估开始时为 0.813 V，100 ps 后为 0.286 V。
DAC8 诊断候选的额外等待由 `Ck<5>` 关闭，bit 4 恰好是取消额外等待后的第一次比较。
前六位等待对照把关闭节点改为 `Ck<4>`，保留四级延时，并检查 FF 与 SS/125°C 的完整无噪声转换。

DAC 驱动和等待时间的单变量对照保持 4 µm 比较器输入对、1 µm 再生/复位管及偏置不变：

- DAC8 改为 DAC16，同时按原分级比例扩大其前级；在 FF/125°C 测无噪声 SNDR，在 TT 测完整 SNDR 和核心功耗。
- 保持 DAC8，将前五位反馈建立延时由四级改为六级；在 FF/125°C 测无噪声 SNDR。

对照均使用原 256 码窗口、统一 18 ns 读码、同一激励与 Spectre AX 设置。
对照结果用于判断建立不足的贡献，并选择完整 PVT/噪声矩阵的候选。

## 完整矩阵暴露的近零差分捕获问题

DAC16、4 µm 输入对、1 µm 再生对的完整 20 项矩阵中，SNDR 为 59.447–61.853 dB，
TT 核心功耗为 2.0393–2.0749 mW，最小转换余量为 1.132 ns。19 项通过。
SS/−40°C 中频含噪声 SNDR 为 60.778 dB，
但第 225 次转换出现一次最低位判决与输出不一致：Valid 后 5 ps 的判决码为 212，输出码为 213。
其余位、比较次数、单调切换及输出保持检查通过；该版本因最低位捕获错误未通过验收。

原始波形中，最低位输入差分约 −0.62 mV。Valid 到达 0.9 V 时，Outp 为 0.973 V、Outn 为 0.0049 V；
5 ps 后 Outp 降至 0.865 V，约 50 ps 后两路输出均低于 0.06 V。
比较器在约 110 ps 后进入复位，Outp 在约 200 ps 后开始回到高电平，Ck0 的捕获上升沿则约在 270 ps。
该转换中 Valid 提前触发了复位，使最低位捕获落在输出返回复位电平的过程中，导致输出保存了错误的最低位。
波形保存于 `lowpower_final_remaining_04/capture_wave.json` 和 `capture_wave.png`。

再生支路对照将交叉耦合再生 NMOS 从 1 µm 加到 2 µm，输入对、复位管、偏置及 DAC16 保持原值。
`lowpower_regen2_adc_01` 三项完整复测通过：原失败条件的 SNDR 为 60.864 dB、捕获错误归零；
SS/125°C 低频含噪声为 59.471 dB、最小转换余量 0.850 ns；TT 低频无噪声为 61.196 dB、2.0765 mW。
该版本的其余 17 项已在 `lowpower_final_remaining_05` 中完成，全部通过。
最终 20 项的最低 SNDR 为 FF/−40°C 中频含噪声的 59.223 dB；
TT 无噪声两频点为 61.196/60.542 dB，含噪声为 60.227/59.586 dB。
上述结果保存在 `lowpower_final_remaining_05/` 与 `lowpower_regen2_adc_01/`；当前电路结果见 [低功耗验收](lowpower-acceptance.md)。
同一序号转换的原始波形显示，2 µm 再生对版本在 Valid 到达 0.9 V 时，Outp/Outn 已为约 0.010/1.800 V，
捕获和输出均保存判决 0。对照波形位于
`lowpower_regen2_adc_01/capture_wave.json` 和 `capture_wave.png`；输入扰动随电路改变，结论以整项捕获检查为准。

# 比较器独立噪声

## 1 µm 再生对：输入对尺寸比较

`lowpower_cmp_noise_02` 在 0.9、0.1125、0.0017578125 V 三个共模点、九个微小差分电压下各重复 128 次。
测试电路包含比较器与 `netlist_lowpower1_mirror` 偏置；比较器的再生管、复位管宽度均为 1 µm。
输入和时钟为理想源，Outp/Outn 各接 20 fF、Valid 接 50 fF；单次评估周期为 4 ns。
以下为输出在 1.8 ns 时达到互补逻辑电平的全部判决，通过二项分布最大似然拟合所得。

| 输入对宽度 | TT 三共模点噪声范围 | SS/125°C 三共模点噪声范围 |
|---|---:|---:|
| 1 µm | 0.678–0.884 mV RMS | 0.775–1.049 mV RMS |
| 2 µm | 0.564–0.610 mV RMS | 0.653–0.694 mV RMS |
| 4 µm | 0.401–0.478 mV RMS | 0.495–0.529 mV RMS |

六个 case 的输出均完成判决，复位检查均为零错误。
SS 下 1/2/4 µm 各有 14/1/1 次 Valid 在 1.8 ns 时尚未达到 1.62 V；对应 Outp/Outn 已达到互补电平。
测量将输出判决与 Valid 上升沿分别统计。
4 µm 的该次 Valid 为 1.616 V，输出为约 0.00073/1.800 V；它对噪声估计的影响低于 0.001 mV。
拟合的统计标准误约 0.027–0.033 mV；未包含瞬态中低频相关性与器件失配。
4 µm 输入对在 FF/125°C 的独立测试为 0.497/0.556/0.532 mV RMS，分别对应上述三个共模点；
3456 次判决无输出未决、无 Valid 延迟超出截止电平、无复位错误，最大 Valid 延迟为 1.325 ns。

## 2 µm 再生对：最终比较器

2 µm 再生对的独立噪声表征沿用上述激励和负载，每个角落为 3456 次判决。
三个共模点依次为 0.9、0.1125、0.0017578125 V：

| 工艺/温度 | 三共模点 sigma（mV RMS） | 最大 Valid 延迟 |
|---|---|---:|
| TT/25°C | 0.383 / 0.437 / 0.414 | 1.151 ns |
| SS/−40°C | 0.281 / 0.373 / 0.369 | 1.279 ns |
| SS/125°C | 0.505 / 0.551 / 0.514 | 1.550 ns |
| FF/125°C | 0.525 / 0.566 / 0.529 | 1.232 ns |

全部 13824 次判决在截止时刻完成，Valid 延迟和复位检查均无错误。拟合 sigma 的统计标准误为约 0.022–0.035 mV。
该表验证改变再生尺寸后的噪声水平；实际 ADC 的反馈复位与捕获关系由系统复测核对。
数据及概率图见 `lowpower_regen2_cmp_01/`，复现入口为
[2 µm 再生对噪声 flow](../../regression/blocks/sar_cmp/studies/noise/README.md)。
