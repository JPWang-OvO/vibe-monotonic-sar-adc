# 架构和共同约定

本设计复现 Liu 等人 2010 年 JSSC 论文的顶板采样、向下单调切换和异步比较完成握手。
目标工艺为 TSMC180，电源及参考为 1.8 V，输入共模为 0.9 V。
论文的 PMOS 输入动态比较器采用串联偏置 PMOS 稳定输入对电流；偏置在本项目内由晶体管电路产生。
论文图 7 的交叉补偿电容依据本设计采样开关的关断耦合测量确定。

每侧 CDAC 的权重为 256、128、64、32、16、8、4、2、1，加一个保持接 VREFP 的单位电容。
当前单位电容 24 fF，每侧总电容 12.288 pF。该数值由 SS125 下实际关断 MOS 结电容残差确定。
两级自举使用 5 V MOS；采样管 W=256 µm，关闭的 PMOS 结补偿 W=384 µm，交叉栅极补偿电容 28 fF。
采样时所有底板接 VREFP，顶板跟踪输入；Sample 下降沿为采样时刻。
第一次比较直接判定采样差分。随后将较高电位侧当前权重的底板由 VREFP 切至 VREFN。
第十次比较只决定 LSB。两个顶板的总电荷分别保持不变。

比较 `Vp >= Vn` 对应判决 1。理想模型在严格相等时输出 1；Python 用有理数运算保持边界一致。
输出为 offset binary，接口为 `D<9:0>`，`D<9>` 为 MSB，差分零对应 512，差分正满量程饱和为 1023。
晶体管比较器在零差分附近的决策属于模拟误差预算，必须同时检查完成时间。

| 模块 | 信号与含义 |
|---|---|
| SAR_PHASE | Clks 250 MHz 输入；Sample 高电平为采样，周期 20 ns，高电平标称 4 ns |
| SAR_SAMPLE | Vin 至 Top 的自举采样开关；Sample/SampleB 为互补控制 |
| SAR_CDAC | Vp/Vn 为顶板；Bp<9:1>、Bn<9:1> 为实际底板电压 |
| SAR_CMP | ClkC 高电平复位，低电平比较；复位 Outp/Outn 同为高，完成后互补；Valid 高表示完成 |
| SAR_ASYNC | Sample 结束后启动比较；每次 Valid 上升推进 Ck<9:0> 中一位，复位比较器并等待 DAC 建立；十位后产生 Done |
| SAR_BIT | Capture 低时锁存器透明且两侧底板预充；Capture 上升后保持 Outp 判决，Bp/Bn 仅一侧下降；Sample 为保留的未用接口 |
| SAR_OUT | Done 上升锁存十位结果；输出保持至下次 Done |
| SAR_BIAS | 由 VDD/VSS 产生比较器 PMOS 电流源的 Bias |

全部数字节点电源域为 VDD/VSS。最终输入及偏置节点的工作范围按晶体管实测记录。
行为层的理想偏置和理想开关仅用于逐模块替换过程。

## 验收版本参数

验收版本的 view 绑定由 `config/final_design.json` 固定。下表对应 `final_*_06`；
阶段结果按实际批次中的绑定和源文件核对。

| 功能 | 实现与尺寸 |
|---|---|
| 五分频与启动 | 五级环形寄存器的器件倍乘为 4；VDD 充电产生上电复位，Clks 低电平锁存复位释放后门控时钟；时钟缓冲 N/P=8/16 µm、L=0.18 µm，Clock 对地 320 fF |
| 采样相位驱动 | SAR_DRIVE 级数倍率 1、8、64、512、4096、32768；后两级由相同实例并联，单实例倍率不超过 512 |
| 比较器 | PMOS 输入对 W/L=8/0.18 µm、nf=2；偏置 PMOS 48/0.36 µm、nf=6；时钟 PMOS 48/0.18 µm、nf=6；NMOS 再生对 8/0.18 µm、nf=2，复位管 8/0.18 µm；感测使用原生 INVD1BWP7T |
| 偏置 | 二极管连接 PMOS 8/0.36 µm；栅接 VDD 的 NMOS 3.6/2 µm；Bias 对地 100 fF |
| 异步等待 | 前四次大权重切换保留建立延迟，其余位由完成握手推进；等待门串联下拉 W=22 µm、nf=4，内部 PMOS 栈节点至 VDD 为 240 fF |
| 采样保护 | 两级反相器与保持逻辑，延迟节点对地 15 fF；实际首比较前采样栅极电压须低于 0.2 V |
| 结果保存 | 静态传输门主从寄存器，EOC 触发；每位后接倍率 1/2 两级输出缓冲及 10 fF 负载 |

五分频器、上电复位、输出寄存器和内部驱动是本项目为固定 TB 边界补全的实现。
5 V 自举器件、24 fF 单位电容及各处耦合补偿来自 TSMC180 模型下的额定电压和建立误差验证。
较大的采样相位驱动用于降低实际自举负载对采样边沿的调制，其功耗包含在 VDD 总功耗中。

# 预定预算

LSB 为 3.515625 mV。量化噪声约为 0.289 LSB RMS，−1 dBFS 输入差分 RMS 为 1.1344 V。
下列预算用于指导模块设计，完整系统必须另外通过规定的 SNDR 验收。

| 误差项 | 输入等效 RMS 预算 |
|---|---:|
| 采样建立与失真 | 0.10 LSB |
| CDAC 建立与寄生引起的信号误差 | 0.10 LSB |
| 比较器动态失调与确定性误差 | 0.18 LSB |
| 关断输入耦合 | 0.08 LSB |
| 全系统采样及比较瞬态噪声 | 0.18 LSB |

各项独立时合计模拟误差约 0.304 LSB RMS；与量化误差平方和合成后约 0.419 LSB。
系统验收直接使用实际码，不以该估算替代仿真。
模块对齐在离判决边界大于 0.5 LSB 时要求判决一致；边界附近允许相邻码，但任何情况都必须完成十次比较。
理想 Python/Verilog-A 层要求逐码一致，逐位差分和共模误差上限 0.01 LSB。

初选转换预算：首比较准备 0.5 ns，十次比较及相邻 DAC 建立合计不超过 13 ns，输出保存 0.5 ns，
留 2 ns 周期裕量。最终电路检查实际采样窗口和最慢一位的完成时间。

# 正式验收激励

VDD 从 0 V 在 10 ns 内线性升至 1.8 V；外部时钟在 20 ns 开始，周期 4 ns，
上升/下降时间各 20 ps，平台高电平宽 1.98 ns，按 50% 电平交点测得占空比 50%。
晶体管分频器通过自身上电复位启动；全部 20 项已检查实际采样周期、窗口和十次比较。
输出每位负载为 10 fF。丢弃前 16 个转换，在其后连续 256 个周期的采样结束后 14 ns 读取输出。
数字低电平判据为 ≤0.18 V，高电平为 ≥1.62 V，中间电平计为无效位。
正式测量设置已固定于 `config/acceptance.json`：瞬态噪声 1 Hz–50 GHz、seed=1，
输出使用两级 SAR_DRIVE（scale=1/2）。频带依据和功耗边界见 `docs/verification/acceptance-method.md`。
