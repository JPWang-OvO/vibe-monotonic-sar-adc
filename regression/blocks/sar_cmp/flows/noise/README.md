# 比较器瞬态噪声

该 flow 比较输入对尺寸对 `SAR_CMP` 输入等效时域噪声的影响，包含比较器与 `SAR_BIAS` 偏置。
测试使用理想差分电压与时钟，Outp/Outn 各接 20 fF、Valid 接 50 fF，沿用已有模块测试负载。
输入管宽度比较 1、2、4 µm，
其余比较器管保持 1 µm 再生/复位、6 µm 偏置/时钟尺寸；偏置选择 `netlist_lowpower1_mirror`。
后续 2 µm 再生对的四角落表征见 [noise_regen2](../noise_regen2/README.md)。

每个 TT/25°C、SS/125°C case 在 0.9、0.1125、0.0017578125 V 共模下，
分别施加 −3、−2、−1、−0.5、0、0.5、1、2、3 mV 差分电压，每档重复 128 次。
每轮随机排列九个电压档，固定排列用于各候选比较，共 3456 次判决。
时钟周期 4 ns，低电平评估窗口 2 ns，20 ps 边沿，在下降沿中点后 1.8 ns 检查结果。
电源用 10 ns 上升，首次比较从 120 ns 开始。

瞬态噪声请求范围为 1 Hz–50 GHz、seed=1，采用 Spectre X AX、每作业 8 线程，
不设置额外积分步长或精度。实际低频下限由 Spectre 根据仿真时长确定，保存在日志。

测量对每个电压档统计有效判决中 Outp 为高的次数，以二项分布最大似然拟合
`P(Outp=1) = Φ((Vdiff − offset)/sigma)`，其中 sigma 为输入等效噪声。
偏移为 50% 判决概率对应的输入差分电压，包含有限样本统计误差。
噪声概率使用 Outp/Outn 达到互补逻辑电平的判决。Valid 在截止时刻尚未达到 1.62 V 的次数单独统计，
延迟为复位前 Valid 跨过 0.9 V 的时间。同时输出未决次数和复位错误；有未决/复位错误时需结合波形审阅，不能直接采用条件拟合的 sigma。
拟合误差条使用局部 Hessian，假设样本独立；单次瞬态中的低频相关性未包含在误差条中。
测量范围为独立比较器与偏置的噪声，CDAC 和采样噪声由 20 项 ADC 系统矩阵覆盖；器件失配尚未验证。

从项目根目录使用公共 runner 的 `prepare --flow regression/blocks/sar_cmp/flows/noise/flow.json`，
审阅生成的 preview 与实际输入后执行、收集。结果中的 `curves` 保存各电压档的全部计数与拟合。
`regression/blocks/sar_cmp/test_noise_fit.py` 用已知概率曲线检查噪声和偏移估计，
并检查没有可辨识概率过渡时不会返回有效噪声结论。
